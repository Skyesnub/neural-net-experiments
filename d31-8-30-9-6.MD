## What is the neural network trying to learn?

The weights and biases for each student (in my case) represent how the predictions are calculated. Training changes these weights and biases to generate more favorable predictions

## Why is ReLU important?

ReLU is important because it allows neural networks to represent non-linear relationships. The original linear multiclass classifier couldn't do my grading problem because it was a non-linear relationship. ReLU and an extra hidden layer helps bridge that gap by killing some neurons, which helps create "kinks" in the decision boundaries.

## What does a neuron really calculate?

The logits are calculated with the hidden / output weights and biases, which is propogated over multiple layers. The activation indicates which neurons were  dead and which neurons were alive, which will be useful later on.

## Forward Pass Review
### Given: X.shape = (100, 2), layer_sizes = [2, 8, 8, 5]

### What is the shape of weights[0]?
[2,8], When matrix multipled with X, should produce [100,8] matrix for the logits for the next layer
### What is the shape of biases[0]?
[8], When added to X, should add the corresponding values to each column.
### What is the shape of the first logits?
[100,8], X @ weights[0] = [100,8]
### What does one number in the first logits matrix represent?
One logit represents the weighted combination of the inputs to one neuron, plus that neuron's bias.
### What does ReLU do to those logits?
ReLU makes the negative logits 0, essentially cancelling them out, which allows the neural network to be able to represent non-linear things.
### What becomes the input to the second layer?
The first activation
### What is the shape of the output logits?
[100,5] for 5 classes and 100 students
### Why are there 5 output neurons?
There are 5 classes, FDCBA
### What does softmax do?
It translates the output logits into probabilites that sum up to 1, where higher numbers in the original array are equal to higher probabilites in the softmax array.

## Backprop Review

### At the output layer:
```bash
error.shape = (100, 5)
weights[-1].shape = (8, 5)
```
Why do we calculate:
```bash
hidden_error = error @ weights[-1].T
```
And what shape do we get?

We calculate the hidden error using that equation because we need to calculate the error that was caused by those weights. The reason we transpose is because the matrix would not multiply correctly if we didn't. The output shape should be [100,8], which should also represent error for the next layer when we do:

```bash
hidden_error = error @ weights[-2].T
```

### Why can't we instead just pass hidden_error back unchanged through a ReLU layer?

We can't do this because hidden_error would have the wrong dimensions, and also that would not help edit the other hidden layers. (I'm also not too sure what this question is asking, my interpretation was why can't you just pass the hidden error back and thats the end of backprop)

The actual question was asking why just do no relu gradient. That's because the gradient should not change for those neurons that are off, so the update it multiplied by 0 or 1 depending on the relu gradient.

For the first layer, why does

```bash
weight_gradient = X.T @ error
```

give us the gradient for the weights?

It gives us the gradient for the weights because it calculated how each individual weight contributes to the error.

### Imagine one specific weight in the network. What is backpropagation actually trying to figure out when it calculates that weight's gradient?

For one specific weight, backprop is actually trying to figure out how much that specific weight contributed to the error through X.T @ error. This weight gradient will then get subtracted from the weights * a learning rate which is the update. This determines which direction the weights will be changed.

### Why does backprop need to go through the network backwards instead of simply calculating the error at the output and changing all the weights based on that same error?

It needs to go through the network backwards because changing all the weights based on that same error will not take into account the process of going through those multiple hidden layers. (Each layer affects the layer after it)

## Adam Review

### What does the first moment (weight_moments) keep track of?

weight_moments keeps track of the recent gradients, and where they are going based on what weight_moments was before and decay1

### What does the second moment (squared_gradient_averages) keep track of?

squared_gradient_averages keeps track of the magnitude of what the squared gradients were, which is basically the magnitude of the gradient measured.

### Why does Adam divide by sqrt(second_moment)?

The second moment will normalize the update based on how large the second moment was in the past which will prevent things from happening like where something thats 0.001 gets a tiny update compared to 10.

### Why do we need bias correction when both moments start as zero?

It fixes the distortion caused by both moments starting at 0.

### What do decay1 = 0.9 and decay2 = 0.999 actually control?

decay1 is for the first moment and decay2 is for the second moment, and they control how much Adam remembers from the past.

## Ultimate Review - The Entire Process Summaritzed

### Forward Pass

Starting out with the weights and biases, the first set of logits are created using activation @ weights + biases. Then, ReLU is used on that set of logits, and that becomes the new set of logits for the next layer. This is repeated until the end, when the output logits are created. Then, the probabilities are created using softmax, which converts a list of numbers into probabilities that sum up to 1. The predictions that the model will make at that time are caused by the probabilities.

### Backward pass

While doing the forward pass, all (the necessary) information was saved that will be useful. For backprop, the neural network loops backwards through the saved logits and calculates the error for each logit. Then, the update gradients are based on that error and the value of the logits, while also being passed through its corresponding ReLU gradient so that the gradients don't update parts where the neurons were deactivated. Then, it updates those weights and moves backwards to the next set of weights and biases.

### Adam

Adam takes into account the direction and scale of the gradients. With Adam you can customize how much you want the neural network to remember of the past magnitude / direction and how much the update will take that into account. Bias correction also happens, which is because it prevents distortion when the weights and biases are initialized at 0.
